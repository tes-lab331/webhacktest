Tentang demo ini

Halaman ini meniru cara banyak aplikasi lama memeriksa login: menempelkan input pengguna langsung ke dalam query, tanpa memisahkannya (bandingkan dengan prepared statement yang dibahas di presentasi). Karena situs ini statis (GitHub Pages), tidak ada database sungguhan — query di atas cuma ditampilkan dan dicek oleh JavaScript, supaya konsepnya tetap bisa dipraktekkan tanpa server.

Setelah login, lanjutkan ke halaman dashboard untuk demo Broken Access Control (IDOR), atau ke halaman ulasan produk untuk demo stored XSS.

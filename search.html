Demo Reflected XSS — lewat parameter URL (?q=...)

Coba buka URL ini langsung (bisa dibuat dari Termux):
search.html?q=<img src=x onerror=alert('XSS')>

Kenapa ini bisa terjadi?

Halaman ini mengambil nilai parameter q langsung dari URL, lalu menampilkannya ke halaman sebagai HTML mentah (bukan teks biasa). Karena isinya datang dari URL — bukan dari database — ini disebut reflected XSS: payload tidak tersimpan, tapi langsung "dipantulkan" ke korban begitu link-nya dibuka. Biasanya disebar lewat link yang kelihatan tidak mencurigakan (dipendekkan, atau disisipkan parameter tersembunyi).

Perbaikan sebenarnya: tampilkan nilai q sebagai teks biasa (textContent), dan jangan pernah memasukkan input dari URL langsung ke dalam HTML.

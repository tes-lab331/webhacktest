Demo Broken Access Control (IDOR) — A01 OWASP Top 10

Memuat...
Coba ini saat presentasi: login dulu (misalnya sebagai budi, id=2), lalu di address bar ganti ?id=2 jadi ?id=1 atau ?id=3. Data user lain — termasuk saldo admin — ikut terlihat, padahal kamu tidak login sebagai mereka.

Kenapa ini bisa terjadi?

Halaman ini mengambil data langsung berdasarkan id di URL, tanpa mengecek ulang apakah id tersebut memang milik pengguna yang sedang login. Perbaikannya: setiap permintaan data harus diverifikasi di sisi server terhadap sesi login yang sah, bukan dipercaya begitu saja dari input pengguna.
